# AI Chatbot for Doctor Appointment Booking

## 📌 Overview
This project is an AI-powered chatbot built using n8n to automate doctor appointment booking through a conversational interface.

## ⚙️ Features
- Appointment booking via chat
- Date & time selection
- Google Calendar integration (create & search events)
- AI-based conversation handling (OpenRouter)

## 🛠 Tech Stack
- n8n
- OpenRouter API
- Google Calendar API
- REST APIs

## 🚀 Workflow
Telegram → AI Agent → Calendar Check → Book Appointment → Response

## 📂 Files
- workflow.json → n8n workflow file
